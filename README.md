# 🏠 Villa Agency - Real Estate Contact Web Page

A responsive, self-contained HTML5 & CSS3 real estate contact portal component built with Bootstrap 5 and FontAwesome 6.

---

## ✨ Features

- **📱 Fully Responsive Design**: Mobile-friendly layout optimized across all screen sizes.
- **✉️ Interactive Contact Form**: Client-side form handling and submission success feedback.
- **🗺️ Integrated Google Map**: Embedded location map for real estate agency office.
- **🎨 Modern UI Component**: Modern typography, custom buttons, and font icon integrations.

---

## 🛠️ Built With

- **HTML5**: Semantic web page markup.
- **Bootstrap 5**: Responsive grid and form styling.
- **FontAwesome 6**: Vector icons for contacts and social links.
- **Google Fonts**: [Poppins](https://fonts.google.com/specimen/Poppins).

---

## 🚀 How to Open

Open `index.html` directly in any web browser.
